One rule: homework has no date. Each class and subject has one line of homework from its Lesson Plan, in order. Today's homework is always the next one not given yet.
  1. 📍 We are here. Ask the teacher which homework the class last did, and set it once.
  2. ➕ Put in. The next homework goes into the live week for that day, replacing what is there for that subject. It goes to parents at 4 PM, in the Student Diary and, if the school has ERP, the parent app.
  3. When it has reached parents, the line moves on by itself. If it didn't go, it comes again the next day. Nobody ticks anything, and the teachers' app isn't needed.
  4. No workbook? The line is the Lesson Plan's own homework (book-back exercises, homework notes) in order, numbered Homework 1, 2, 3… in each chapter.
  5. Class test: the day before, the homework is “Tomorrow class test — what to revise”. It goes even on a day without homework for that subject, and the test is on the next school day.
Nothing in the live Homework Planner changes until you press Put in for a class.
