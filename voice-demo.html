🔧 How to Add Voice to Your Pages

Add this single line to any DigiSmartSchool page — then use DSVoice anywhere in your JavaScript.

<!-- Step 1: Add to <head> of any page --> <script src="voice-engine.js"></script> // Step 2: Speak any text — auto-detects Tamil/English/Math DSVoice.speak("இன்று நாம் fractions பற்றி கற்போம்"); // Step 3: Specify mode for context-aware voice DSVoice.speak("x² + 5x + 6 = 0", { mode: 'teaching' }); DSVoice.speak("சாபாஷ்! Correct!", { mode: 'feedback' }); // Step 4: Set student level (adjusts speed globally) DSVoice.setLevel('beginner'); // slower DSVoice.setLevel('intermediate'); // default DSVoice.setLevel('advanced'); // faster // Step 5: Convenience shortcuts DSVoice.teachConcept("Newton's First Law states..."); DSVoice.tellStory("In 1789, the French Revolution began..."); DSVoice.giveFeedback("That's almost right! The answer is 42."); DSVoice.readRevision("Photosynthesis: 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂"); DSVoice.askQuestion("What is 2+2?", ["3","4","5","6"]); // Step 6: Math conversion const spoken = DSVoice.Math.convert("a² + b² = c²"); // → "a squared plus b squared equals c squared" // Step 7: Stop speech DSVoice.stop();
